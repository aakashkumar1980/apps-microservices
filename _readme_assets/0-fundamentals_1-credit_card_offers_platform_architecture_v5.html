📖 Introduction
🎯 Offer Lifecycle & User Journey

The Credit Card Offers Platform manages the complete lifecycle of promotional offers for cardmembers. Marketing teams create campaigns through the Campaign Management Portal, defining offers such as "10% cashback at Whole Foods" or "3X points on dining". Each offer includes targeting rules, budget limits, and approval workflows.

Eligible cardmembers discover these offers through the Offers Discovery Portal on web and mobile. When a customer enrolls in an offer and makes a qualifying purchase - for example, spending $100 at a restaurant - the Transaction Processing System sends real-time transaction data to our platform. The Transaction Matching Service identifies the match, the Rewards Engine calculates the reward, and the amount is credited to the customer's account.

All events are streamed to the Data Lake via AWS Kinesis for analytics and reporting. Processed data is sent to downstream systems including Statement System, Finance, Compliance, and Customer 360 Platform.

🔗 System Integration
⬆️ Upstream Integrations

Inbound Integrations: The platform receives data from internal enterprise systems (Core Banking, Transaction Processing, CRM, Marketing Platform) and external third-party systems (Partner feeds, Merchant data). Batch files are received daily for merchant data and customer segments.

Outbound Integrations: The platform calls both internal enterprise APIs (Fraud Detection, KYC/AML verification) and external third-party APIs (Partner Inventory, Credit Bureau, Geolocation, Currency Exchange) through Istio Service Mesh.

⬇️ Downstream Integrations

Processed data is pushed to internal enterprise systems including Statement System, Enterprise Notification Platform, Finance (General Ledger), Compliance & Audit, Enterprise Data Warehouse, and Customer 360 Platform.

📊 Platform Summary

The platform comprises 20+ Spring Boot microservices organized into 6 domains: Campaign & Offer, Customer, Transaction & Redemption, Rewards & Settlement, Merchant & Partner, and Communication. Each domain owns its data in Couchbase NoSQL database.

3 Vert.X high-throughput services handle millions of events daily: Offer Impressions Service (tracks offer views), Click Stream Service (tracks user interactions), and Real-time Transaction Matcher (instant transaction-to-offer matching for push notifications). These services use non-blocking I/O to process 50,000+ events per second at peak.

8 Node.js aggregator services provide optimized API responses for UI portals by combining multiple backend calls into single responses.

6 scheduled batch jobs run during off-peak hours for heavy processing: Eligibility Refresh (nightly pre-computation for 50M+ customers), Offer Expiry (deactivate expired offers and enrollments), Daily Settlement (calculate partner payouts), Report Generation (KPI dashboards and executive summaries), Partner Settlement (weekly invoice generation), and Data Archival (monthly move to cold storage).

Key Technologies: Apache Kafka (event-driven messaging), Couchbase (NoSQL with full-text search), Redis (distributed caching), AWS API Gateway (rate limiting, WAF), Okta (OAuth2/OIDC), AWS Kinesis (event streaming), and Istio Service Mesh (egress proxy with mTLS).

⬇️ UPSTREAM SYSTEMS (Inbound → Platform)

External systems that send data to our Offers Platform. This data is essential for eligibility evaluation, transaction matching, and offer personalization. Security protocols vary based on data sensitivity - PCI-DSS compliant systems use OAuth2 with mTLS, internal systems use OAuth2, and bulk transfers use encrypted SFTP.
🏢 INTERNAL (Enterprise Systems)
🔐 High Security OAuth2 mTLS
🏛️ Core Banking System (FIS / Fiserv)
Source of truth for customer identity and account information. Provides customer account details, card type (Gold, Platinum), credit limits, and account status. This data is used to validate customer eligibility and personalize offers based on card tier and spending capacity.
Customer Accounts API Card Details API Credit Limits API Account Status API
💳 Transaction Processing System (Visa/Mastercard)
Processes all card payments globally. Sends real-time transaction feed including authorization events (card swipe), settlement events (payment cleared), and refund events. This feed enables our platform to match transactions against enrolled offers within seconds of purchase.
Real-time TXN Feed Authorization Events Settlement Events Refund Events
🔑 Standard Security OAuth2
👤 CRM System (Salesforce)
Customer Relationship Management system that tracks all customer interactions. Provides customer preferences (favorite categories, communication channel), support history, and interaction logs. This data enhances offer personalization and helps customer service agents resolve offer-related queries.
Customer Preferences Support History Interaction Logs
📢 Marketing Platform (Adobe Campaign)
Enterprise marketing automation platform. Provides audience segments created by marketing analysts (e.g., "High-value diners", "Grocery shoppers"), campaign triggers for coordinated promotions, and A/B test group assignments. These segments are used for offer targeting rules.
Audience Segments Campaign Triggers A/B Test Groups
📦 Batch Transfer SFTP + PGP
📊 Marketing Data Warehouse
Analytics team's data warehouse containing customer behavioral insights. Daily files include customer segment assignments (e.g., "Premium Diners", "Weekly Grocery Shoppers"), eligibility lists for specific campaigns, and spend profiles. Used for batch eligibility pre-computation.
Customer Segments Eligibility Lists Spend Profiles
🌐 EXTERNAL (3rd Party Systems)
🔑 API Integration OAuth2
🏪 Partner Systems (Retail/Dining/Grocery)
External partners like Whole Foods, Cheesecake Factory, and Costco send their offer inventory through API Gateway. This includes offer details they're willing to fund (e.g., "10% cashback on purchases over $50"), availability windows, and pricing updates. Each partner has dedicated API credentials with rate limits.
Offer Inventory Feed Availability Updates Pricing Updates
📦 Batch Transfer SFTP + PGP
🏪 Merchant Data Provider (Mastercard/Visa Data)
Provides master database of all merchants globally. Daily files include merchant profiles (name, location, category), MCC codes (Merchant Category Codes - 5411 for Grocery, 5812 for Restaurants), and location updates. This data is critical for accurate transaction-to-merchant matching.
Merchant Master File MCC Code Updates Location Data

⬆️ UPSTREAM SYSTEMS (Outbound ← Platform via Istio)

External APIs that our platform calls for additional data or validation. All outbound calls are routed through Istio Service Mesh which handles mTLS certificate management, circuit breaker patterns, retry policies, rate limiting, and audit logging for compliance.
🏢 INTERNAL (Enterprise APIs)
🔐 High Security OAuth2 mTLS
🚨 Fraud Detection Platform
Enterprise fraud detection services using machine learning. Called during redemption processing to score transaction risk. Returns a fraud score (0-100) based on velocity patterns, geographic anomalies, and behavioral signals. High-risk redemptions are flagged for manual review.
Fraud Score API Risk Assessment API Velocity Check API
🔐 KYC/AML Verification
Know Your Customer and Anti-Money Laundering verification services. Called during high-value offer enrollments to verify customer identity and check against watchlists. Required for regulatory compliance in financial services.
Identity Verification API Watchlist Check API Document Verification API
🌐 EXTERNAL (3rd Party APIs)
🔐 High Security OAuth2 mTLS
🏪 Partner Inventory Systems
Real-time inventory APIs from retail and dining partners. Before displaying an offer, the platform verifies availability and current pricing. For example, checking if a restaurant promotion is still active or if a grocery store's offer has reached its redemption limit. Called during offer browse and enrollment flows.
Whole Foods API Cheesecake Factory API Costco API Shake Shack API
📊 Credit Bureau Systems
Credit reporting agencies for eligibility verification. Called when evaluating customers for premium offers with higher reward tiers. Returns credit score ranges and account standing. Highly regulated - calls are logged for compliance and only made with appropriate consent flags.
Experian API TransUnion API Equifax API
🔑 Standard Security API Key
📍 Address & Location Services
Address validation and standardization services. Merchant addresses from transaction data are often incomplete or formatted inconsistently. These APIs clean addresses and return standardized formats, enabling accurate merchant matching for location-based offers.
Google Places API SmartyStreets API HERE Maps API
🌍 Geolocation Services
Geographic coordinate and distance calculation services. Used for "restaurants near me" features and location-based offer targeting. Also validates transaction locations for fraud detection - flagging transactions occurring in multiple distant locations within short timeframes.
Google Maps API Mapbox API
💱 Currency Exchange Services
Real-time foreign exchange rate APIs. Used for international transactions and multi-currency reward calculations. When a cardholder makes a purchase abroad, the platform converts the transaction amount to calculate the correct reward value in the account's base currency.
XE Currency API Open Exchange Rates
